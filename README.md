# 💼 My Portfolio

Welcome to my **personal portfolio** built with **Next.js**!
This project showcases my **skills, projects, and experience** in a modern, responsive, and high-performance way.

---

## 🚀 Features

* ⚡ **Next.js** for fast, server-side rendering
* 📱 **Responsive design** for all screen sizes

---

## 📦 Getting Started

You can run this project **locally** or using **Docker**.

### 🧰 Prerequisites

* [npm](https://www.npmjs.com/)
* [Docker](https://www.docker.com/) *(optional)*

---

## ⚡ Quick Start

### ▶️ Run Locally

```bash
# Navigate to the project directory
cd portfolio

# Install dependencies
npm install

# --- Development ---
# Start the app in development mode
npm run dev

# OR
# --- Production ---
# Build the project for production
npm run build

# Start the production server
npm run start
```

---

### 🐳 Run with Docker

```bash
# Build and start the Docker container
docker-compose up --build
```

---

## 🌐 Accessing the Project

After running the app **locally** or with **Docker**, you can view your portfolio in the browser:

👉 **[http://localhost:3000](http://localhost:3000)**
